Guidelines

Follow these rules to ensure consistency when using the OpenMined brand.

Do
  • Use the provided SVG logo files at all times
  • Maintain sufficient clear space around the logo
  • Use the dark-background variant on dark surfaces
  • Use the mono-black variant when color is unavailable
  • Use Rubik for headings (H1–H4) and Inter for body text
  • Reference design tokens for consistent colors and spacing
Don't
  • Stretch, rotate, or distort the logo
  • Change the logo colors or add effects
  • Place the full-color logo on busy backgrounds
  • Recreate the logo with different fonts
  • Use low-resolution raster versions of the logo
  • Mix brand colors arbitrarily outside the token system
