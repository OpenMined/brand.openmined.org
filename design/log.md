- **2026-10-30** — **Examples** (new page, `/examples/`): a starter set of self-contained pages built only from the files the site serves — a landing section, product steps, press cards, a join form over the gradient map, a long read, a dashboard in the minimal layer, and the three ABC diagrams. - **2026-10-30** — **New components**, to v1's set and the ones openmined.org uses (launch parity): page base (`page.css`) and color mode (`theme.js`), cards (with an icon, in a grid), tags, tables, tabs, accordions, steps, code block copy, table of contents, pagination, and two link-card variants (logo on a white plate; post with a cover). Shown on Interface.
- **2026-10-30** — **Three statuses** (decision, design lead): `draft`, `released`, `deprecated`. Every `exploring` and `working` token and guidance file is now `released`, ahead of launch; the production build fails on any `draft`, and `npm run build:review` shows drafts. Pages show a status only when it isn't `released`.
- **2026-10-28** — **The accent is a hue** (decision, design lead): `--accent-subtle`, `-soft`, `-fg` and `-key` point at green's roles, as the statuses do; elements stay gray at rest. - **2026-10-28** — Minimal fields take a faint 1px outline on hover (the controls' hover line, gray 300 light, gray 500 at 0.5 dark), no pointer light. Field hover applies only where a pointer can hover.
- **2026-10-28** — Minimal content links draw their green line in from the left on hover and leave to the right, like the full link but still in color, instead of fading the underline's color. Plain background lines, so it works in any browser.
