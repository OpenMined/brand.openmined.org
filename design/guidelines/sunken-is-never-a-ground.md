---
type: Guideline
title: Sunken is never a ground
description: The sunken level is a well set into a surface, for a control or for content. Never a page, a section or a band.
status: draft
tags: [surfaces]
tokens: [--surface-sunken]
---

**Rule.** Use `--surface-sunken` for a recess set into a surface: a field, a toggle or progress track, a hover wash, or a well holding content (a demo, a figure, an excerpt). Never for a page, a full-width section, a band or a sidebar.

**Why.** A well reads as set into what's around it. Used as a large background, sunken stops being a recess: it breaks the elevation model and darkens the page.

**Do.** Set a demo or a figure into a sunken well, on the page or on a card. Put a sunken track inside a card: a recessed control goes on a raised surface ([Recessed controls prefer a raised surface](#guidelines-controls-on-a-raised-surface)).

**Don't.** Make a whole section, band or sidebar sunken. Put a block of code in a sunken well: code blocks are always dark (*Surfaces*).
