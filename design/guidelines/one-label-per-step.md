**Rule.** Text on a fill takes one color per step, the same in every hue: ink on 100–300, white on 500–800.

**Why.** Picking the label per hue makes a row of badges mix dark and white text.

**Watch: the key (500).** The key keeps each hue's own lightness, so white doesn't reach 4.5:1 on all of them (3.8:1 on green and amber). The strong status chip uses it anyway, with the contrast flagged, until interface text is worked out. An earlier version of this rule kept text off the key entirely; that clause was removed on 9 Oct 2026 as interface design ahead of its time.

**Swatch readouts** (hex values printed on a color sample) follow one color per step too: ink from 50 to 400, white from 500 up. The new steps (50, 400, 900, 950) have no interface label rule yet.
