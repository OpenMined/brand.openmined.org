---
type: Guideline
title: Graphics draw from the palette
description: No separate color scheme for graphics. Every graphic color is a palette step or a gradient stop.
status: working
tags: [graphics]
---

**Rule.** Don't hand-pick colors for a graphic beside the palette. Use palette steps and the gradient; if a graphic needs a color the palette doesn't have, extend the palette or the gradient instead.

**Why.** A palette edit has to reach every graphic. A second set of colors would have to be kept in step by hand, and wouldn't be.

**Priority.** The palette is used far more for web pages and graphics than for app interfaces. When a color choice trades one against the other, weigh pages and graphics first.
